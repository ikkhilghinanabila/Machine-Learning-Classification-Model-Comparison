# Machine Learning Classification Model Comparison

## Deskripsi
Proyek ini bertujuan untuk membangun dan membandingkan beberapa
model machine learning untuk menyelesaikan permasalahan klasifikasi.

## Model yang Digunakan
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Tahapan Analisis
1. Data preprocessing
2. Exploratory Data Analysis (EDA)
3. Pembagian data training dan testing
4. Training beberapa model
5. Evaluasi model
6. Hyperparameter tuning
7. Pemilihan model terbaik

## Evaluasi
Performa model dievaluasi menggunakan:
- Accuracy
- Precision
- Recall
- F1-Score

## Tools
- Python
- Google Colab
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
